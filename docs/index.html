ESTADOS, CIDADES E CÓDIGOS DO IBGE (ELEM. MULTIPLOS COMBINADOS)

Você pode utilizar dois ou mais elementos em conjunto, fazendo com que um retorne as
informações necessárias do outro, um exemplo são os Estados, Cidades e os Códigos do IBGE,
outro exemplo possível é utilizar o estados para selecionar os aeroportos, ao selecionar
somente o estado serão retornados todos os aeroportos daquele mesmo estado, caso selecione
alguma cidade será retornado os aeroportos somente daquela cidade.

Atributos:
lzaz-id="ID-PARA-FAZER-JUNÇÃO" - Usado em todos os campos como atributo, para que
um campo se comunique com outro eles devem possuir o mesmo lzaz-id.

Classes:
lzaz-estados - Classe para SELECT que deve receber estados.
lzaz-cidades - Classe para SELECT que deve receber cidades.
lzaz-ibge-estado - Classe TEXT INPUT para receber IBGE estados.
lzaz-ibge-cidade - Classe TEXT INPUT para receber IBGE cidades.
lzaz-iata - Classe para SELECT que deve receber info. IATA.
